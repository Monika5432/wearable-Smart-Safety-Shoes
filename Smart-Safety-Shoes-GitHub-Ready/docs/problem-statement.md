# Problem Statement

Women may not always be able to access or operate their phone during an emergency — it can be out of reach, locked, or too risky to pull out and use in front of a threat. Personal-safety solutions that rely entirely on a phone inherit that same single point of failure.

A discreet wearable system integrated into everyday footwear removes that dependency: the trigger is built into something the user is already wearing, and the alert path doesn't require unlocking a screen, opening an app, or speaking.

## What we're building toward

Smart Safety Shoes combine an embedded controller, an emergency trigger, location acquisition, and a communication mechanism into one footwear-integrated system, so that raising an alarm and sharing a location with predefined contacts takes one discreet action — not several deliberate ones.

## Why this framing matters for the build

Because the core constraint is *discretion under stress*, every design decision downstream — trigger placement, activation gesture, feedback method — is evaluated against a simple test: would this still work if the user couldn't look at, hold, or speak into anything?
